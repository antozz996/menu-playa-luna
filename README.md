# Playa Luna — Menu Asporto

Esportazione dei file pubblicati su https://playa-luna-menu.vercel.app/ (12 novembre 2026).

## Struttura
- index.html: homepage
- css/style.css: stili
- js/app.js: interazioni e traduzioni
- js/prodotti.js: prodotti, prezzi e categorie
- img/: immagini e logo
- qr/: QR code del menu

## Pubblicazione su Vercel
Importare il repository GitHub in Vercel, configurando Framework Preset: Other e Root Directory: ./ ; Build Command vuoto e Output Directory vuota (root). Non creare un nuovo progetto Vercel se si vuole mantenere il dominio esistente: collegare Git al progetto playa-luna-menu gia presente.

Nota: questo archivio ricostruisce il sito statico dal deployment pubblico; non include eventuali file locali non distribuiti in produzione.
